# 🔴 PokéDexDaily

Uma Pokédex interativa desenvolvida com **HTML, CSS e JavaScript**, que permite descobrir diferentes Pokémon de forma rápida e divertida.

A cada nova descoberta, o projeto busca um Pokémon aleatório e apresenta suas principais informações.

## ✨ Funcionalidades

* 🎲 Pokémon aleatório a cada descoberta
* 🖼️ Imagem oficial do Pokémon
* 🔢 Número da Pokédex
* 🏷️ Tipos do Pokémon
* 📊 Estatísticas
* ⚔️ Ataques
* 💡 Curiosidade e descrição
* 📏 Altura e peso
* 📱 Interface totalmente responsiva
* 🎨 Interface inspirada no universo Pokémon
* 🔄 Dados carregados dinamicamente através da API

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* PokeAPI
* Vercel

## 🌐 API

Os dados dos Pokémon são obtidos através da **PokeAPI**.

🔗 https://pokeapi.co/

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela:

* 💻 Desktop
* 💻 Notebook
* 📱 Tablet
* 📱 Smartphone

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/pokedex-daily.git
```

Entre na pasta:

```bash
cd pokedex-daily
```

Depois, abra o arquivo `index.html` no navegador.

Você também pode utilizar a extensão **Live Server** no VS Code para executar o projeto localmente.
